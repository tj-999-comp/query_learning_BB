DESIGN.md の「midnight command console」を、ネイビー・ゴールド・シルバーのブランド配色へ翻訳した5案です。カードを開いて、問題選択からSQL実行までの見え方を比較できます。

01 / Command Console

分析画面を主役にする、情報密度の高い王道ダッシュボード。

02 / Scoreboard

試合速報のような緊張感で、問題を1問ずつ進める構成。

03 / Light Inversion

暗いSQLワークスペースと、明るい説明エリアを大胆に反転。

04 / Fieldhouse

スポーツ施設の掲示板を思わせる、親しみやすいカード型UI。

05 / Focus Mode

問題文・エディタ・結果だけに集中できる、静かな学習画面。
