# SQL練習帳 MVPアプリ

静的ホスティングで配信するブラウザ内SQLiteの学習画面です。

## 起動

1. `Apps/data/csv/` に8つのCSVを配置する。
2. リポジトリルートで `python3 Apps/scripts/import_csv_to_sqlite.py` を実行する。
3. リポジトリルートで `python3 -m http.server 8000` を実行する。
4. `http://localhost:8000/Apps/app/` を開く。

SQLiteファイルがまだない場合も、問題一覧と画面構成は確認できますが、SQLの実行は無効になります。

## MVPの判定仕様

- `SELECT` または `WITH` で始まる単一の読み取りSQLだけを許可する。
- 期待結果は問題定義の参考SQLを同じSQLiteへ実行して生成する。
- SQL文ではなく、結果の列数・行数・列位置ごとの値を比較する。
- 問題定義で行順を無視する場合は、行の並びを正規化して比較する。
- 正解した問題だけを達成済み・正解数としてブラウザ内に保存する。
- お気に入りは手動で切り替え、ブラウザ内に保存する。
