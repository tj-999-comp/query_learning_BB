# SQL練習帳 MVPアプリ

静的ホスティングで配信するブラウザ内SQLiteの学習画面です。

## 起動

1. `Apps/data/csv/` に8つのCSVを配置する。
2. リポジトリルートで `python3 Apps/scripts/import_csv_to_sqlite.py` を実行する。
3. リポジトリルートで `python3 -m http.server 8000` を実行する。
4. `http://localhost:8000/Apps/app/` を開く。

SQLiteファイルがまだない場合も、問題一覧と画面構成は確認できますが、SQLの実行は無効になります。

## MVPの判定仕様

- `SELECT` または `WITH` で始まる単一の読み取りSQLだけを許可する。
- 期待結果は問題定義の参考SQLを同じSQLiteへ実行して生成する。
- SQL文ではなく、結果の列数・行数・列位置ごとの値を比較する。
- 問題定義で行順を無視する場合は、行の並びを正規化して比較する。
- 問題定義に `numericTolerance` がある場合、数値は指定された差以内を同じ値として比較する。
- 問題文に指定のない丸めや表示形式は、正誤条件にしない。
- 正解した問題だけを達成済み・正解数として保存する。公開環境ではBasic認証に紐づくサーバー保存を正本とし、Mac・iPad・Windows間で同期する。
- お気に入りは手動で切り替え、サーバーへ同期する。同期できない場合はlocalStorageへ保存し、復旧時に再送する。

## SQLエディタ

SQL入力欄はCodeMirrorによるSQLエディタです。キーワードの構文ハイライト、行番号、括弧対応、インデントを利用できます。

- `Tab`でインデント、`Shift + Tab`でインデントを戻す。
- `Cmd + Enter`（Mac）または`Ctrl + Enter`（Windows/Linux）で「実行する」を実行する。
- `Cmd/Ctrl + /`でコメントアウトを切り替える。
- `Alt + 上/下`でカーソル行または選択行を上下に移動する。
- クォーテーションと括弧は開閉セットで自動入力される。
- キーボードショートカットでは正誤判定を行わない。
- エディタが読み込めない場合はtextareaへフォールバックし、読み取り専用SQL制限は常に適用する。

## SQL補完

SQL補完はCodeMirrorのshow-hint拡張で表示し、入力中または`Ctrl`/`Cmd` + `Space`で起動できます。候補にはSQLキーワード、利用可能なテーブル・ビュー、読み込んだSQLiteのカラムを含め、候補の確定は`Tab`、終了は`Esc`です。候補を確定すると半角スペースが自動で挿入されます。テーブル別・エイリアス別のカラム候補も表示します。

候補のスキーマ取得元は、画面で読み込んだSQLiteデータベースの`sqlite_master`と各テーブルの`PRAGMA table_info`です。固定リストは持たず、データベース読み込みのたびに再取得するため、SQLiteを再生成して公開する運用で候補も更新されます。
